## 集合的記憶ワーク（Collective Memory Work）

**概要**
集合的記憶ワーク（Collective Memory Work）は、フェミニスト社会学者ハイジ・ドースルバーグが1983年に開発した、グループメンバーが共通テーマについての個人的記憶を書き・語り・集合的に分析することで、社会的構造・規範・権力が個人の経験に与える影響を明らかにする参加型研究・学習手法である。

**理論的背景**
フェミニスト認識論（「個人的なことは政治的」）・批判的心理学（ケン・ガーゲン）・ポスト構造主義的記憶論が基盤。「個人の記憶は孤立したものではなく、社会的言説・集合的記憶・文化的規範によって形成される」という前提が核心。コレクティブ・バイオグラフィーと近接するが、記憶という特定の対象と分析の集合性に焦点を当てる。

**実践方法・プロセス**
① テーマ選定：集合的に探求したいテーマを決定（例：「初めて自分が女性であると感じた瞬間」）。② 記憶の書き出し：各自が指定テーマの記憶を三人称で書く（距離感を保つ工夫）。③ 読み合わせと分析：記憶を順番に読み上げ、共通パターン・差異・社会的要素を分析。④ 理論化：個人的記憶から社会的・文化的力学を抽出して理論化する。⑤ 変革的示唆の引き出し：分析から生まれる批判的気づきを実践的変革の起点とする。

**ファシリテーションでの活用**
ジェンダー・多様性・組織文化・コミュニティ歴史を探求するワークショップに活用される。「記憶を読む」行為を通じて、個人的体験に宿る社会的力学への集合的理解を深める。

**効果と限界**
社会的構造への批判的気づきと集合的変革意識の育成に強い力を持つ。しかし感情的に重い記憶への配慮・安全な対話空間の確保・専門的ファシリテーターの存在が不可欠。
