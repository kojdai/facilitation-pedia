## トランザクティブ・メモリー・システム

**概要**
トランザクティブ・メモリー・システム（Transactive Memory System: TMS）は、集団が「誰が何を知っているか」を共有する集合的な記憶システムであり、メンバーが互いの専門性・知識・スキルを把握することで、情報を効率的に保存・引き出し・統合する能力を高める集団認知のメカニズムである。

**理論的背景**
ダニエル・ウェグナーが1985年に提唱した。カップル・親友・チームなどの緊密な関係において、「自分が覚えること」と「他者を通じて知ること（他者を外部記憶として使うこと）」が分担されることで、集団全体としての認知能力が個人の総和を超えることを示した。エドウィン・ハッチンスの分散認知と深く関連する。チーム・パフォーマンス研究では、TMSの発達がチームの問題解決速度・正確さ・創造性と強く相関することが実証されている。

**実践方法・プロセス**
TMSをファシリテーションに活用する実践：
1. **専門性の可視化**：チームメンバーそれぞれが持つ専門性・知識・スキルを明示的に共有・記録する（スキル・マトリクス等）
2. **誰に何を聞くかの明確化**：「このトピックはAさん、あれはBさんに」という方向づけを集団内に育てる
3. **クロス・トレーニング**：お互いの専門性・役割・知識の一部を共有する「横断的学習」機会を設ける
4. **知識共有の儀式**：定期的な「誰が何を知っているか」の更新セッション（ナレッジ・フェア等）を設ける
5. **信頼と信頼性の構築**：他者の専門性を信頼して委ねる関係性と、任された責任を果たす信頼性を育てる
6. **新メンバーのオンボーディング**：新しいメンバーが迅速に集団のTMSに統合されるプロセスを設計する

**ファシリテーションでの活用**
チームのキックオフ・ワークショップ、多職種チームの連携改善、プロジェクト・チームの知識管理、組織内ナレッジマネジメントの設計、新チームの立ち上げ支援に活用。「誰が何を知っているかを知る」という集団的なメタ認知能力の向上は、チームの効率と革新性を高める。

**効果と限界**
TMS研究は「誰が何を知っているか」の共有がチームのパフォーマンスを向上させることを多くの実験で実証している。特に複雑な課題・緊急時の意思決定でTMSの強いチームが優れた成果を示す。ただし専門性の固定化（「あの人はあれしかしない」）がチームの柔軟性を損なう場合がある。また信頼関係が欠如するとTMSは機能しない。
