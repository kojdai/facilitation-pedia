## 社会ネットワーク分析（Social Network Analysis）

**概要**
社会ネットワーク分析（Social Network Analysis; SNA）は、個人・組織・概念などの「ノード（nodes）」と、それらを結ぶ「関係（ties）」のパターンを数学的・視覚的に分析する研究方法論・組織分析ツールである。誰と誰がつながっているか・情報がどのように流れるか・誰が中心的役割を果たすかを明示する。

**理論的背景**
ゲオルク・ジンメルの社会学・クルト・レヴィンのグループダイナミクス・モレノのソシオメトリーが歴史的先行研究。グラノベッターの「弱い紐帯の強さ（1973年）」・バートの「構造的空白（Structural Holes）」が理論的発展の重要な貢献。

**主要な中心性指標**
1. **次数中心性（Degree Centrality）** — 直接のつながりの数
2. **媒介中心性（Betweenness Centrality）** — 他者をつなぐ橋渡し役
3. **固有ベクトル中心性（Eigenvector Centrality）** — 影響力の高いノードとのつながり
4. **近接中心性（Closeness Centrality）** — 全ノードへのアクセスのしやすさ

**ファシリテーションでの活用**
組織診断・変革推進者の特定・知識共有の促進・コミュニティ開発・コラボレーション強化のワークショップで使われる。「誰と誰がつながっていないか（構造的空白）」の可視化が介入ポイントを示す。

**効果と限界**
組織の非公式ネットワークを可視化する強力なツール。ただしデータ収集・プライバシー・分析ツールへのアクセスが実践上の課題。
