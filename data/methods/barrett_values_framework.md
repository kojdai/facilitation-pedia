## バレット・バリューズ・フレームワーク（Barrett Values Framework）

**概要**
バレット・バリューズ・フレームワーク（Barrett Values Framework）は、リチャード・バレットがマズローの欲求階層とウィルバーの4象限を統合して開発した、個人・組織・コミュニティの価値観を測定・変革するフレームワークである。Cultural Values Assessment（CVA）という測定ツールとともに150カ国以上で使われている。

**7レベルの意識**
1. 生存（Survival）
2. 関係（Relationships）
3. 自尊（Self-Esteem）
4. 変容（Transformation）
5. 内的一貫性（Internal Cohesion）
6. 貢献（Making a Difference）
7. 奉仕（Service）

**ファシリテーションでの活用**
組織文化診断・価値観に基づくリーダーシップ開発・合併後の文化統合・組織ビジョン策定で使われる。CVAの結果をグループで共有し、「望ましい文化」と「現在の文化」のギャップを対話する起点として使う。
